# Оценка пригодности фотографий автомобилей: эвристическое базовое решение

Код и данные к курсовой работе «Разработка программной системы автоматической оценки качества и пригодности изображений автомобилей» (часть 1, теоретическая).

Версия, по которой получены таблицы и рисунки курсовой, зафиксирована тегом **`coursework-sem1`**. Ветка `main` может меняться во второй части работы; для проверки курсовой берите тег.

## Состав

| Папка | Что внутри |
|---|---|
| [`baseline/`](baseline/) | эвристическое базовое решение (модуль `quality_baseline`), запуск, проверка воспроизводимости, сохранённые результаты |
| [`parser/`](parser/) | парсер объявлений Авто.ру, которым собраны фотографии |
| [`dataset/`](dataset/) | 140 фотографий из 8 объявлений Авто.ру (испытания в разделе 2.4) и 35 фото предварительного набора `pics_with_auto_for_test` |

## Связь с QualityJPG

Базовое решение построено на ядре оценки из проекта автора [QualityJPG](https://github.com/arphset/QualityJPG---Made-in-Abyss). Ядро вынесено в отдельный модуль без веб-интерфейса, базы данных и языковой модели и адаптировано для фотографий автомобилей: добавлены режим `car` (классы car/truck) и контекстные проверки главного фото, резкость считается по области автомобиля в размере показа, пороги экспозиции учитывают белые кузова и тёмные шины, все пороги и веса собраны в `config.py`. Полный перечень отличий — в [`baseline/README.md`](baseline/README.md#отличия-от-qualityjpg). Репозиторий QualityJPG при этом не изменялся.

## Как воспроизвести результаты курсовой

```bash
git clone https://github.com/arphset/baseline_car_pics_rate
cd baseline_car_pics_rate
git checkout coursework-sem1
cd baseline
pip install -r requirements.txt
python check_reproduction.py
```

Скрипт заново оценивает все 140 фотографий и сравнивает балл, техническую годность и решение «годится на главное фото» с сохранёнными результатами. Ожидаемый вывод:

```
Фото: 140, принято на главное: 33, расхождений: 0
```

Проверено на Python 3.13, CPU, с версиями из `baseline/requirements.txt`; веса детектора `yolov8n.pt` (SHA-256 `f59b3d83…c83b36`) ultralytics скачивает при первом запуске.

## Данные

Фотографии загружены собственным парсером из публичных объявлений Авто.ру и используются только в учебных целях. Права на снимки принадлежат авторам объявлений. Для каждого объявления в `meta.json` сохранены ссылка на объявление и адреса исходных фотографий (для объявления `1133546958-473be5c0` файл meta.json не сохранился). Разметки пригодности у этого набора нет: метрики точности, полноты и F1-меры на нём не считаются, это будет сделано во второй части работы на размеченном датасете.

Изображения дополнительных проверок (`test_images_hard`, `test_images_hires`) в репозиторий не включены: часть из них взята из открытых репозиториев примеров детекторов, и лицензия снимков не проверялась. Их разметка и результаты лежат в `baseline/`.
