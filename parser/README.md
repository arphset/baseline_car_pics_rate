# Парсер объявлений Авто.ру

Скачивает все фотографии объявления в исходном разрешении (версия `/orig` с CDN), в том порядке, в котором их разместил продавец, и сохраняет рядом `meta.json` со ссылкой на объявление и адресами фотографий. Капчу и вход парсер не обходит: при капче он останавливается, а в режиме `--browser` страница открывается в Chrome, и капчу решает человек.

```bash
uv sync                                  # или: pip install requests selenium webdriver-manager
python main.py urls30.txt              # файл со ссылками на объявления, по одной в строке
python main.py urls30.txt --browser    # то же через Chrome, капчу решает человек
```

Фотографии сохраняются в `dataset_auto_ru/<id объявления>/`. Набор из [`../dataset`](../dataset) получен этим парсером из объявлений списков `urls30.txt` и `urls_spare.txt`; в набор вошли 8 объявлений, папка переименована в `dataset`.
