# Испытания бэйзлайна на фото из объявлений Авто.ру

140 фото из 8 объявлений (папка `dataset`, все фото каждого объявления, без отбора). Запуск: `python run_baseline.py ../dataset/<объявление> --mode car --out results/dataset/<объявление>` (или `python check_reproduction.py` для всех восьми сразу).

- `<объявление>/report.csv, results.csv, results.json` – вывод run_baseline.py по каждому объявлению.
- `all_results.csv` – все 140 фото в одной таблице (разделитель `;`, открывается в Excel). Колонка «тип кадра (просмотр)» – грубая группа, проставленная при визуальном просмотре снимков; это не разметка, и метрики по ней не считаются.
- `sheets/` – контактные листы: под каждым фото номер, балл, MAIN = принято на главное, car = автомобиль найден, crop = обрезан.
- `fig_ds_scores.png`, `fig_ds_verdicts.png` – графики из раздела 2.4 курсовой.

## Итоги
- Средний балл 8,6, медиана 9,5; технически годных 80, автомобиль найден на 82, принято на главное 33.
- Отказы: автомобиль не найден 58, обрезан 36, меньше 30 % кадра 11, другие машины/животное 2.
- По просмотру: спереди/сбоку/3/4 спереди 34 (принято 21), сзади/3/4 сзади 24 (принято 12), детали 21 (0), салон/багажник/мотор 61 (0).
- Ни одного дефекта резкости (мин. индекс 0,78); 5 дефектов экспозиции, все на снимках салона.
- Время: в среднем 2,6 с на фото, медиана 1,8 с (CPU).
